# 월급잔액

세전 월급으로 **실수령을 추정**하고, 습관 지출(커피·배달·OTT 등)을 빼서 **이번 달 남는 돈**을 보여주는 단일 화면 웹앱입니다.  
로그인·백엔드 없음. 브라우저에서만 동작합니다.

## 로컬에서 열기

**방법 1 — 파일 직접 열기**

```bash
# macOS
open index.html

# Linux (예시)
xdg-open index.html
```

또는 파일 탐색기에서 `index.html`을 더블클릭하세요. (`file://` 로도 동작합니다.)

**방법 2 — 간단 서버**

```bash
cd /workspace/salary-leftover   # 또는 이 폴더 경로
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

## 사용법

1. **세전 월급**을 입력하면 실수령(추정)이 바로 바뀝니다.
2. 습관 행의 **− / +** 또는 숫자로 월 횟수를 조절하세요. (단가도 수정 가능)
3. **습관 추가**로 나만의 항목을 넣을 수 있고, **×**로 삭제합니다.
4. 큰 숫자 = **실수령 − 습관 합계**. 마이너스면 빨강, 여유 있으면 청록.
5. **요약 복사하기**로 `세전 / 실수령 / 습관 / 잔액` 텍스트를 클립보드에 복사합니다.

## 계산 공식 (추정 · 세무 자문 아님)

앱 UI의 「계산 기준 보기」에도 동일한 내용이 있습니다.

### 4대보험 (근로자 부담, 단순화)

세전 × **9.4%**

| 항목 | 비율 |
|------|------|
| 국민연금 | 4.5% |
| 건강보험 | ≈ 3.545% |
| 장기요양 | 건강보험의 ≈12.81% → 세전 대비 ≈0.454% |
| 고용보험 | 0.9% |
| **합계** | **≈ 9.4%** |

### 소득세·지방소득세 (추정 실효세율)

월 세전 구간별 **거친** 실효세율입니다. 근로소득공제·부양가족·비과세는 반영하지 않습니다.

| 월 세전 | 실효세율 |
|---------|----------|
| ~200만 | 0.5% |
| ~300만 | 2.0% |
| ~400만 | 3.5% |
| ~500만 | 5.0% |
| ~700만 | 7.5% |
| ~1000만 | 10.0% |
| 1000만+ | 13.0% |

### 잔액

```
실수령 ≈ 세전 − 4대보험 − 소득세추정
잔액   = 실수령 − Σ(단가 × 월 횟수)
```
